# HRI 모델 검증 보고서

**분석 단위:** 전국 229개 시·군·구
**종속변수:** `outflow_cost_ratio` (관외 의료이용률, KOSIS 거주지 기준 진료현황 2024)
**Robustness 종속변수:** `unmet_std_pct` (미충족 의료 표준화율, 지역사회건강조사 2024)
**수치 출처:** `reports/hri_weights.json`, `reports/hri_run.txt` (`hri model` 실행 결과)

## 1. 모델

```
HRI_i = w_wai · WAI_i + w_iai · IAI_i − w_dpi · DPI_i        (229곳 기준 0–100)
세 지수로 관외이용률을 LASSO 회귀(5-fold CV로 α 선택)하고, |회귀계수| 비율을 가중치로 쓴다.
```

## 2. 가중치 추정 결과

| | w_wai | w_iai | w_dpi |
|---|---|---|---|
| 점추정 | **0.454** | **0** | **0.546** |
| 부트스트랩 평균 (n=100) | 0.484 | 0.046 | 0.470 |
| 부트스트랩 95% 구간 | [0.003, 0.732] | [0, 0.179] | [0.176, 0.899] |

**LASSO 계수 (α = 0.144)**
- WAI → 관외이용률: **−0.0017** (인력↑ → 관외 이용↓)
- IAI → 관외이용률: **0** (LASSO가 제거)
- DPI → 관외이용률: **+0.0020** (수요압력↑ → 관외 이용↑)

IAI가 빠진 이유: WAI와 IAI의 상관이 0.66이고, OLS로 셋을 다 넣어도 IAI 계수는 +0.0005로 작고 방향도 반대다. 구간이 넓은 것에서 보이듯 가중치는 안정적이지 않다.

## 3. 내부 검증

| 지표 | 값 |
|---|---|
| In-sample R² (n=229) | 0.244 |
| **Holdout R², 80:20 분할 200회** | **중앙값 0.213**, 사분위 0.127~0.269, 음수 비율 7.5% |
| Holdout R², 분할 1회 (seed 42, n=46) | −0.362 |
| 같은 분할의 RMSE / MAE | 0.153 / 0.113 (관외이용률은 0~1 비율) |

분할 1회 값이 음수인 것은 종로구(WAI 100, 전체 중앙값 11.3)가 검증셋에 들어간 탓이다. 그 한 곳의 예측(0.06)과 실제(0.59) 차이가 검증셋 오차 제곱합의 27%다. 분할에 따라 결과가 크게 달라지므로 분포를 기준으로 본다.

## 4. 외부 검증 — 가중치 추정에 쓰지 않은 지표와의 상관

| 지표 | Pearson | Spearman |
|---|---|---|
| `unmet_std_pct` (표준화 미충족의료율) | −0.059 | −0.045 |
| `unmet_crude_pct` (조율 미충족의료율) | −0.027 | −0.043 |
| `outflow_patient_ratio` (환자수 기준 관외이용률) | −0.380 | −0.400 |

부호는 모두 음수(HRI↑ ↔ 미충족·관외 ↓)이지만 미충족의료율과는 사실상 무상관이다. 환자수 기준 관외이용률은 종속변수와 같은 자료에서 나온 것이라 독립적인 검증이 아니다.

## 5. Robustness — 미충족의료율을 종속변수로 재추정

| | 관외이용률 (채택) | 미충족의료율 |
|---|---|---|
| In-sample R² | 0.244 | 0.019 |
| 가중치 (WAI, IAI, DPI) | 0.454, 0, 0.546 | 0, 0.920, 0.080 |

미충족의료율로는 세 지수가 거의 아무것도 설명하지 못하고, 가중치도 전혀 다르게 나온다. 가중치가 종속변수 선택에 크게 좌우된다는 뜻이다.

## 7. WAI 자료 교체 전후

의사·전문의 수를 시·도 값 분배에서 시·군·구 실측(요양기관 단위 자료 집계, 2024.12)으로 바꿨다.

| | 시·도 값 분배 | 시·군·구 실측 |
|---|---:|---:|
| WAI 계수 | +0.0020 | −0.0017 |
| 가중치 (WAI, IAI, DPI) | 0.241, 0.431, 0.328 | 0.454, 0, 0.546 |
| In-sample R² | 0.274 | 0.244 |
| Holdout R² 중앙값 (200회) | 0.243 | 0.213 |
| HRI–미충족의료율 Pearson | −0.134 | −0.059 |

부호는 바로잡혔고, 설명력과 외부 상관은 나아지지 않았다. "이전" 열은 간호사 로더 버그(관련 열이 전부 0이던 문제)를 고친 뒤의 값이다.

## 8. 알려진 한계

1. IAI 가중치가 0이라 인프라 변화가 HRI에 반영되지 않는다.
2. 가중치의 부트스트랩 구간이 넓다.
3. WAI는 대형병원 소재지 몇 곳이 극단값이다(왜도 3.45).
4. 간호사·장비·특수진료실은 여전히 시·도 값을 인구 비례로 나눈 것이다.
5. 사망원인 자료가 시·도 단위뿐이라 치료가능사망률로 외부 검증하지 못했다.
6. 미충족의료율은 시·군·구당 응답자 중앙값 848명으로 잡음이 크다.
