# HRI 모델 검증 보고서

**기준 연도:** 2024년
**분석 단위:** 전국 229개 시·군·구
**메인 종속변수:** `outflow_cost_ratio` (관외 의료이용률, KOSIS 거주지 기준 진료현황)
**Robustness 종속변수:** `unmet_std_pct` (미충족 의료 표준화율, 지역사회건강조사 2024)

## 1. 모델

```
HRI_i = w_wai · WAI_i + w_iai · IAI_i − w_dpi · DPI_i        (0–100)
LASSO 5-fold CV로 가중치 추정. 종속변수에 대한 |회귀계수|를 합산 1로 정규화.
```

## 2. 가중치 추정 결과

| | w_wai | w_iai | w_dpi |
|---|---|---|---|
| 점추정 (옵션 A) | **0.236** | **0.407** | **0.357** |
| 부트스트랩 평균 (n=100) | 0.232 | 0.403 | 0.365 |
| 95% CI (옵션 A) | [0.150, 0.275] | [0.278, 0.487] | [0.260, 0.537] |

**Raw LASSO 계수**
- WAI → outflow_cost_ratio: +0.0019 (예상과 부호 반대 — WAI 시도 평탄화 한계)
- IAI → outflow_cost_ratio: **−0.0032** (인프라↑ → 관외 이용↓, 직관 ✓)
- DPI → outflow_cost_ratio: **+0.0028** (수요압력↑ → 관외 이용↑, 직관 ✓)

## 3. 내부 검증

| 지표 | 값 |
|---|---|
| In-sample R² | 0.272 |
| 5-fold CV R² | 0.287 |
| Holdout test R² (n=46) | 0.127 |
| Holdout RMSE | 0.122 (관외이용률 단위 = 비율) |
| Holdout MAE | 0.096 |
| LASSO α (최적) | 0.024 |

## 4. 외부 검증 — 옵션 B (미충족의료율) 와의 상관

| 외부 지표 | Pearson | Spearman |
|---|---|---|
| `unmet_std_pct` (표준화 미충족율) | −0.130 | −0.112 |
| `unmet_crude_pct` (조율 미충족율) | −0.104 | −0.117 |
| `outflow_patient_ratio` (환자수 기준 관외) | −0.137 | −0.232 |

부호는 모두 음수(HRI↑ ↔ 미충족·관외 ↓), 직관과 일치하지만 절대값은 약함.

## 5. Robustness — 옵션 B를 메인으로 재추정

| 지표 | 옵션 A (메인) | 옵션 B (robust) |
|---|---|---|
| R² | 0.272 | 0.015 |
| w_wai | 0.236 | 0.870 |
| w_iai | 0.407 | 0.130 |
| w_dpi | 0.357 | 0.000 |

→ 옵션 B는 데이터 노이즈가 커서 모델 fit이 매우 약하다. **옵션 A를 메인으로 채택하는 결정이 정당화된다.**

## 6. HRI Face Validity

**TOP 10 (복원력 ↑)** — 서울 강남·서초·종로·송파·마포·중구·광진·영등포·강동, 대구 중구
**BOTTOM 10 (복원력 ↓)** — 경북 의성·영덕·청송·청도·영양·봉화·성주·고령, 충남 서천·부여

도심-거점 vs 농촌-군 구분이 명확. 선행연구가 지목하는 "비수도권 의료 소외"가 정확히 잡힘.

## 7. 알려진 한계

1. **WAI의 시도 평탄화**: HIRA 인력 데이터가 시·도 단위만 있어 시·군·구로 인구비례 분배. 같은 시도 내 시·군·구는 동일 per_100k → WAI 시·군·구 변별력이 시·도 평균에 종속. WAI의 회귀계수 부호가 직관과 일치하지 않는 원인.
2. **사망원인 데이터도 시·도 단위만**: OECD 치료가능사망률을 시·군·구로 외부 검증할 수 없음 — Phase 2 확장 시 HIRA 시·군·구 데이터를 받아오는 것이 우선.
3. **응답 표본**: 미충족의료율은 시·군·구당 응답자가 800~1500명 수준. 잡음이 큼.

## 8. 정책적 활용

본 HRI는 모델 fit이 완벽하지 않지만, **시·군·구 의료 자원 분포의 정량 지수**로서 일관된 face validity를 보인다. Phase 6 정책 시뮬레이션에서 WAI/IAI/DPI 변수를 개입 변수로 사용해 ΔHRI를 추정함으로써 정책 우선순위 도출에 활용 가능하다.
