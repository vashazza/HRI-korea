# HRI 모델 검증 보고서

**분석 단위:** 전국 229개 시·군·구
**종속변수:** `outflow_cost_ratio` (관외 의료이용률, KOSIS 거주지 기준 진료현황 2024)
**Robustness 종속변수:** `unmet_std_pct` (미충족 의료 표준화율, 지역사회건강조사 2024)
**수치 출처:** `reports/hri_weights.json`, `reports/hri_run.txt` (`hri model` 실행 결과)

## 1. 모델

```
HRI_i = w_wai · WAI_i + w_iai · IAI_i − w_dpi · DPI_i        (229곳 기준 0–100)
세 지수로 관외이용률을 LASSO 회귀(5-fold CV로 α 선택)하고, |회귀계수| 비율을 가중치로 쓴다.
```

## 2. 가중치 추정 결과

| | w_wai | w_iai | w_dpi |
|---|---|---|---|
| 점추정 | **0** | **0.476** | **0.524** |
| 부트스트랩 평균 (n=100) | 0.186 | 0.531 | 0.282 |
| 부트스트랩 95% 구간 | [0, 0.378] | [0.410, 0.690] | [0.108, 0.580] |
| LASSO에 남은 비율 (부트스트랩) | 58% | 100% | 100% |

**LASSO 계수 (α = 0.311)**
- WAI → 관외이용률: **0** (LASSO가 제거)
- IAI → 관외이용률: **−0.0016** (인프라↑ → 관외 이용↓)
- DPI → 관외이용률: **+0.0018** (수요압력↑ → 관외 이용↑)

WAI가 빠진 이유: WAI와 IAI의 상관이 0.91이라 둘이 사실상 같은 축이고, IAI가 관외이용률과 조금 더 강하게 관련된다(상관 −0.40 대 −0.33). 부트스트랩 100회에서 IAI는 매번, WAI는 58%만 남는다. OLS로 셋을 다 넣으면 WAI 계수는 +0.0044로 뒤집히는데, 다중공선성 때문이지 인력이 관외이용을 늘린다는 뜻이 아니다(WAI와 DPI만 넣으면 −0.0027). 가중치는 WAI·IAI의 상대적 중요도가 아니라 공급과 수요의 비중으로 읽어야 한다.

## 3. 내부 검증

| 지표 | 값 |
|---|---|
| In-sample R² (n=229) | 0.266 |
| **Holdout R², 80:20 분할 200회** | **중앙값 0.277**, 사분위 0.169~0.339, 음수 비율 8% |
| Holdout R², 분할 1회 (seed 42, n=46) | 0.106 |
| 같은 분할의 RMSE / MAE | 0.124 / 0.100 (관외이용률은 0~1 비율) |

WAI·IAI가 대형병원 소재지 몇 곳에 몰려 있어(종로구, 대구 중구 등) 그 지역이 검증셋에 들어가느냐에 따라 분할 1회 값이 크게 흔들린다. 분포를 기준으로 본다.

## 4. 외부 검증 — 가중치 추정에 쓰지 않은 지표와의 상관

| 지표 | Pearson | Spearman |
|---|---|---|
| `unmet_std_pct` (표준화 미충족의료율) | −0.069 | −0.051 |
| `unmet_crude_pct` (조율 미충족의료율) | −0.038 | −0.044 |
| `outflow_patient_ratio` (환자수 기준 관외이용률) | −0.410 | −0.442 |

부호는 모두 음수(HRI↑ ↔ 미충족·관외 ↓)이지만 미충족의료율과는 사실상 무상관이다. 환자수 기준 관외이용률은 종속변수와 같은 자료에서 나온 것이라 독립적인 검증이 아니다.

## 5. Robustness — 미충족의료율을 종속변수로 재추정

LASSO가 세 계수를 모두 0으로 만든다(R² 0). 세 지수는 미충족의료율을 설명하지 못한다. 이 경우 코드는 가중치를 1/3씩으로 돌려주지만 의미 있는 추정이 아니다.

## 6. 순위의 모습

## 7. 공급측 자료 교체 전후

요양기관 단위 자료(2024.12)를 시·군·구로 집계해, 시·도 값을 인구 비례로 나누던 변수를 두 차례에 걸쳐 교체했다.

| | ① 전부 시·도 값 분배 | ② 의사·전문의 실측 | ③ + CT·MRI·수술실·분만실 실측 |
|---|---:|---:|---:|
| WAI 계수 | +0.0020 | −0.0017 | 0 |
| IAI 계수 | −0.0036 | 0 | −0.0016 |
| 가중치 (WAI, IAI, DPI) | 0.241, 0.431, 0.328 | 0.454, 0, 0.546 | 0, 0.476, 0.524 |
| WAI–IAI 상관 | 0.87 | 0.66 | 0.91 |
| IAI의 PC1 설명분산 | 33.3% | 33.3% | 44.0% |
| In-sample R² | 0.274 | 0.244 | 0.266 |
| Holdout R² 중앙값 (200회) | 0.243 | 0.213 | 0.277 |
| Holdout R², seed 42 | 0.145 | −0.362 | 0.106 |
| HRI–미충족의료율 Pearson | −0.134 | −0.059 | −0.069 |

①은 간호사 로더 버그(관련 열이 전부 0이던 문제)를 고친 뒤의 값이다. ②에서 IAI가 0이 된 것은 IAI의 주요 입력이 아직 시·도 값이었기 때문이고, ③에서 그것까지 실측으로 바꾸자 반대로 WAI가 0이 됐다. CT·MRI만 바꾸고 수술실·분만실은 그대로 둬도 가중치는 (0, 0.428, 0.572)로 같은 방향이다.

## 8. 알려진 한계

1. WAI와 IAI가 분리되지 않는다(상관 0.91). WAI 가중치가 0이라 인력 변화가 HRI에 반영되지 않는다.
2. 가중치의 부트스트랩 구간이 넓다.
3. WAI·IAI는 대형병원 소재지 몇 곳이 극단값이다(왜도 3.45, 3.02).
4. 간호사는 여전히 시·도 값을 인구 비례로 나눈 것이다.
5. 사망원인 자료가 시·도 단위뿐이라 치료가능사망률로 외부 검증하지 못했다.
6. 미충족의료율은 시·군·구당 응답자 중앙값 848명으로 잡음이 크다.
